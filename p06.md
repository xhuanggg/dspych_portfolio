This portfolio piece is an improvement / extensions of the model
reported in this poster:
<https://drive.google.com/file/d/1nnV-cHYAQVcc5l6ge7PP3fHaVXDlSpSQ/view?usp=sharing>.

What’s going on is to find out how promximal minority stressors, such as
internalized homophobia and lack of LGBTQ+ affirmation, would predict
distal stressors–discrimination through behavioral enactment of LGBTQ+
identity–acts of coming out.

A critique of the model in the poster is using the count of specific
coming-out strategies participants used in each of the five categories
as mediators. Using counts of specific strategies is problematic for two
reasons. First, participants were given more specific strategies to
choose from in some categories and participants were given fewer
specific strategies to choose from in other categories. Therefore, the
scales of the counts are not uniform, which makes it harder to
understand the coefficients. Second, using counts introduces a
methodological confound. After indicating they had used strategies of a
category, participants were given a given a list of specific strategies
under a category and they reported the specific strategies they had
used. Then, participants were asked a series of follow-up questions
regarding each specific strategy they had used, such as whether they
were comforable with using it. After this, participants were given a
list of specific strategies of another category. Therefore, the problem
is that participants might be annoyed by the number of follow-up
questions if they reported using a lot of specific strategies. So they
may simply report they had used fewer specific strategies as they got
tired with the follow-up questions.

On top of that, I added internalized problems as another outcome
variable.

Thus, a simple solution to these concerns is to treat the mediators as
dummy variables. This introduces some challenges. First, I need to
calculate the indirect effects by specifying new variables that the
product of a-paths and b-paths because there is not an off-the-rack
indirect effect command for categorical mediators in mplus. Second,
doing this requests a lot of computation. It takes more than three hours
to run this model with a powerful mac.

discrim_cfa  <- mplusObject(
  
  TITLE = "Experiences of Discrimination CFA;",

   "usevar =

   "estimator = MLR;

   "discrim by Discrim1-Discrim5; ! *free factor loading

# Initialize the number of parcels
num_parcels <- 3

# Create empty lists to hold item names and a vector for loadings sum for each parcel
parcels <- vector("list", num_parcels)
parcels_loadings <- numeric(num_parcels)

# Distribute items across parcels to balance the sum of loadings
for (i in 1:nrow(discrim_cfa_loading.std.sorted)) {
  # Find the parcel with the smallest sum of loadings
  min_index <- which.min(parcels_loadings)
  
  # Add the current item to this parcel
  parcels[[min_index]] <- c(parcels[[min_index]], discrim_cfa_loading.std.sorted$param[i])
  parcels_loadings[min_index] <- parcels_loadings[min_index] + discrim_cfa_loading.std.sorted$est[i]
}

# Name parcels for clarity
names(parcels) <- paste0("Parcel", 1:num_parcels)

# Calculate and print the summed loadings for each parcel
summed_loadings <- parcels_loadings
names(summed_loadings) <- names(parcels)
print(summed_loadings)
