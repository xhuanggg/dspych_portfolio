factors. Usually, this is done with dummy coding.

## Regression with dummy coding

In this case, the coefficients of the IVs are simple slopes, or simple
effects in an ANOVA. Therefore, what is problematic here is that I
cannot estimate the main effects like an ANOVA. A potential consequence
is that, if I would like to run a mediation model extending from this
regression, I cannot estimate the indirect effects of the main effects
of the IVs.

``` r
reg_dummy <- lm(rtidx ~ v + t + vt, data = df)
summary(reg_dummy)
```

## Replicating the ANOVA with a smarter coding scheme

A way to solve this problem is to ditch dummy coding and to code the IVs
as -0.5 and 0.5

``` r
df$t <- ifelse(df$Condition == "OPR" | df$Condition == "OPB", -0.5, 0.5) # 0 = self, 1 = other
df$v <- ifelse(df$Condition == "SPB" | df$Condition == "OPB", -0.5, 0.5) # 0 = private, 1 = public
df$vt <- df$v*df$t
df$rt <- df$rtidx
```

``` r
reg_anova <- lm(rtidx ~ v + t + vt, data = df)
summary(reg_anova)
```

The regression replicated the ANOVA results. Built upon this, we can do
two things. First, we can run mediation if we are interested in the
indirect effects of the ANOVA main effects. Second, this simply makes
ANCOVAs more intuitive. No need to learn how to run an ANCOVA. Just add
controls into the above regression.
